# Hazmat Handling

Hazardous materials handling workflow with UN classification, SDS documentation, proper labeling, certified handler assignment, and emergency response procedures.

**Domain:** logistics  
**Complexity:** 4/5  
**Tags:** [hazmat-handling, dangerous-goods, un-classification, sds-documentation, dot-compliance, emergency-response]

## Lanes
- **Receiving** - Identifies hazmat, verifies documentation
- **Safety/Compliance** - Validates classification, ensures compliance
- **Certified Handler** - Handles, stores, and ships hazmat

## Process Flow
1. Identify hazardous material by UN number
2. Verify Safety Data Sheet (SDS) available
3. Confirm proper DOT classification
4. Assign certified hazmat handler
5. Verify proper PPE and equipment
6. Apply required labels and placards
7. Store in designated hazmat area
8. Document chain of custody
9. Prepare emergency response info for shipping
