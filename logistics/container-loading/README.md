# Container Loading

Container loading workflow with load plan optimization, weight distribution, cube utilization maximization, seal application, and bill of lading generation.

**Domain:** logistics  
**Complexity:** 3/5  
**Tags:** [container-loading, load-planning, weight-distribution, cube-utilization, seal-verification, ocean-freight]

## Lanes
- **Load Planner** - Creates load plan, optimizes space
- **Loading Crew** - Executes loading, applies seal

## Process Flow
1. Generate container load plan
2. Optimize for weight distribution
3. Maximize cube utilization
4. Stage cargo at loading dock
5. Load cargo per plan sequence
6. Verify weight limits not exceeded
7. Secure cargo with dunnage
8. Apply container seal
9. Generate bill of lading
