# Customs Clearance

International customs clearance workflow with importer documentation, customs broker HS code classification, duty calculation, customs authority inspection, and clearance certificate issuance.

**Domain:** logistics  
**Complexity:** 4/5  
**Tags:** [customs-clearance, international-trade, customs-broker, hs-codes, import-export, duties-taxes, inspection]

## Lanes
- **Importer** - Submits shipment details and commercial invoices
- **Customs Broker** - Reviews docs, classifies HS codes, files entry
- **Customs Authority** - Inspects shipment, issues clearance certificate

## Process Flow
1. Importer submits shipment details and commercial invoice
2. Customs broker reviews documentation for completeness
3. Classify goods using HS (Harmonized System) codes
4. Calculate applicable duties and taxes
5. File customs entry with authorities
6. Customs determines if physical inspection required
7. Conduct inspection or document review only
8. Decision: cleared or held for investigation
9. Release shipment and issue clearance certificate
