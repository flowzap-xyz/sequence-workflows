# Damaged Goods

Damaged goods processing workflow with damage documentation, carrier claim filing, disposition decision (salvage/dispose), inventory adjustment, and loss tracking.

**Domain:** logistics  
**Complexity:** 3/5  
**Tags:** [damaged-goods, damage-claim, inventory-write-off, carrier-claim, disposition, loss-prevention]

## Lanes
- **Warehouse** - Identifies damage, documents, disposes
- **Claims/Finance** - Files carrier claims, tracks losses

## Process Flow
1. Identify damaged goods during receiving or handling
2. Document damage with photos and description
3. Determine cause of damage (carrier, handling, vendor)
4. File carrier claim if transit damage
5. Assess salvage value
6. Decide disposition (salvage, donate, dispose)
7. Adjust inventory for write-off
8. Track loss for reporting
9. Update loss prevention metrics
