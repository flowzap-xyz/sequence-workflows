# Cycle Counting

Inventory cycle counting workflow with ABC classification, count scheduling, variance investigation, adjustment approval, and inventory accuracy tracking.

**Domain:** logistics  
**Complexity:** 3/5  
**Tags:** [cycle-counting, inventory-accuracy, abc-analysis, variance-investigation, perpetual-inventory, audit]

## Lanes
- **WMS System** - Schedules counts, tracks accuracy
- **Counter** - Performs physical counts
- **Supervisor** - Investigates variances, approves adjustments

## Process Flow
1. Generate cycle count schedule based on ABC class
2. Assign locations to counters
3. Freeze location for counting
4. Perform physical count
5. Compare to system quantity
6. If variance, perform recount
7. Investigate significant variances
8. Approve inventory adjustment
9. Update inventory accuracy metrics
