# Fleet Maintenance

Fleet maintenance workflow with preventive maintenance scheduling, vehicle inspection, work order creation, parts ordering, and DOT compliance tracking.

**Domain:** logistics  
**Complexity:** 3/5  
**Tags:** [fleet-maintenance, preventive-maintenance, vehicle-inspection, work-order, dot-compliance, telematics]

## Lanes
- **Fleet System** - Schedules maintenance, tracks compliance
- **Maintenance Shop** - Performs inspections and repairs

## Process Flow
1. Monitor vehicle mileage and service intervals
2. Generate preventive maintenance alert
3. Schedule vehicle for service
4. Perform pre-service inspection
5. Create work order for required repairs
6. Order parts if needed
7. Complete maintenance work
8. Update service records
9. Return vehicle to active fleet
