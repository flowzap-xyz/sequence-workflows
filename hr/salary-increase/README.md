# Salary Increase

Salary increase workflow with market analysis, comp ratio review, budget validation, tiered approval based on increase percentage, and payroll system update.

**Domain:** hr  
**Complexity:** 3/5  
**Tags:** [salary-increase, compensation, merit-raise, market-adjustment, budget-approval, comp-ratio]

## Lanes
- **Manager** - Submits increase request with justification
- **HR/Compensation** - Reviews market data, validates budget
- **Executive** - Approves increases above threshold

## Process Flow
1. Manager submits salary increase request
2. HR reviews current comp ratio vs market
3. Validate budget availability
4. Route based on increase percentage
5. < 10%: Manager + HR approval
6. 10-20%: Director approval required
7. > 20%: VP/Executive approval required
8. Update payroll system with new salary
9. Generate offer letter for employee
