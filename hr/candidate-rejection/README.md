# Candidate Rejection

Candidate rejection workflow with stage-appropriate messaging, personalized rejection letters, talent pool consideration, ATS status update, and candidate experience feedback.

**Domain:** hr  
**Complexity:** 3/5  
**Tags:** [candidate-rejection, hiring-decision, rejection-letter, talent-pool, candidate-experience, ats-update]

## Lanes
- **Hiring Manager** - Makes rejection decision, provides feedback
- **Recruiter** - Crafts message, sends notification
- **ATS System** - Updates status, archives candidate

## Process Flow
1. Hiring manager decides not to proceed
2. Document rejection reason
3. Determine rejection stage (resume, phone, onsite)
4. Select appropriate rejection template
5. Personalize message with feedback (if appropriate)
6. Consider for talent pool for future roles
7. Send rejection notification
8. Update ATS with final status
9. Archive candidate record
