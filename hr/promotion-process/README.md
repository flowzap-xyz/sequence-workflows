# Promotion Process

Employee promotion workflow with performance validation, job level assessment, compensation adjustment, title change, and announcement coordination.

**Domain:** hr  
**Complexity:** 3/5  
**Tags:** [promotion-process, career-advancement, job-leveling, title-change, compensation-adjustment, succession-planning]

## Lanes
- **Manager** - Nominates employee, provides justification
- **HR** - Validates eligibility, processes changes

## Process Flow
1. Manager nominates employee for promotion
2. Validate performance history meets criteria
3. Assess readiness for next job level
4. Determine new title and job code
5. Calculate compensation adjustment
6. Obtain required approvals
7. Update HRIS with new role and salary
8. Coordinate announcement timing
9. Communicate promotion to employee
