# PTO Request

PTO request workflow with balance verification, manager approval, calendar blocking, and team coverage check before approval.

**Domain:** hr  
**Complexity:** 2/5  
**Tags:** [pto-request, time-off, vacation, leave-management, manager-approval, accrual-balance]

## Lanes
- **Employee** - Submits request, receives approval notification
- **Manager** - Reviews request, checks coverage, approves/denies

## Process Flow
1. Employee submits PTO request with dates
2. System checks available PTO balance
3. Manager receives approval request
4. Check team calendar for conflicts
5. Verify adequate coverage during absence
6. Approve or deny with reason
7. Update employee calendar
8. Deduct hours from PTO balance
