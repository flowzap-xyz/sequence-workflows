# Reference Check

Professional reference check workflow with reference collection, outreach scheduling, structured interview questions, feedback documentation, and hiring recommendation.

**Domain:** hr  
**Complexity:** 3/5  
**Tags:** [reference-check, employment-verification, professional-references, hiring-decision, candidate-vetting, feedback-collection]

## Lanes
- **Candidate** - Provides reference contact information
- **Recruiter** - Conducts reference calls, documents feedback
- **Hiring Manager** - Reviews feedback, makes final decision

## Process Flow
1. Request reference list from candidate
2. Verify references are professional contacts
3. Schedule reference calls
4. Conduct structured reference interview
5. Ask about performance, strengths, areas for growth
6. Verify employment dates and title
7. Document feedback and ratings
8. Compile reference summary
9. Share with hiring manager for decision
