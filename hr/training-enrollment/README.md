# Training Enrollment

Training enrollment workflow with course catalog browsing, manager approval, LMS registration, completion tracking, and certification management.

**Domain:** hr  
**Complexity:** 2/5  
**Tags:** [training-enrollment, learning-management, lms, professional-development, compliance-training, certification]

## Lanes
- **Employee** - Requests training, completes courses
- **Manager/LMS** - Approves enrollment, tracks completion

## Process Flow
1. Employee browses training catalog
2. Select course and submit enrollment request
3. Manager reviews and approves (if required)
4. Register employee in LMS
5. Employee completes training modules
6. Track completion and assessment scores
7. Issue certificate upon completion
8. Update employee training record
