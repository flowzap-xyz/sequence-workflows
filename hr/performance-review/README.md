# Performance Review

Annual performance review workflow with self-assessment, manager evaluation, 360 feedback collection, calibration sessions, and merit increase recommendations.

**Domain:** hr  
**Complexity:** 4/5  
**Tags:** [performance-review, annual-evaluation, goal-setting, 360-feedback, calibration, merit-increase]

## Lanes
- **Employee** - Completes self-assessment, reviews feedback
- **Manager** - Evaluates performance, recommends rating
- **HR/Leadership** - Facilitates calibration, approves increases

## Process Flow
1. HR initiates annual review cycle
2. Employee completes self-assessment
3. Collect 360 feedback from peers
4. Manager completes evaluation
5. Conduct calibration session across teams
6. Finalize performance ratings
7. Determine merit increase recommendations
8. Manager delivers feedback to employee
9. Set goals for next review period
