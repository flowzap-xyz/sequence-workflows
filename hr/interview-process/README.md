# Interview Process

Multi-stage interview process with resume screening, phone screen, technical interview, onsite panel, team consensus decision, and offer/rejection handling.

**Domain:** hr  
**Complexity:** 4/5  
**Tags:** [interview-process, hiring, phone-screen, technical-interview, onsite-panel, talent-acquisition, offer-management]

## Lanes
- **Candidate** - Submits application, completes interviews, receives decision
- **Recruiter** - Reviews resumes, conducts phone screens, schedules interviews
- **Hiring Team** - Conducts technical and onsite interviews, makes hiring decision

## Process Flow
1. Candidate submits application
2. Recruiter reviews resume against requirements
3. If qualified, schedule phone screen
4. Conduct phone screen and evaluate fit
5. If passed, schedule technical interview
6. Hiring team conducts technical assessment
7. If technical skills sufficient, schedule onsite panel
8. Conduct onsite interviews with multiple team members
9. Team reaches consensus on hire/no-hire decision
10. Extend offer or send rejection notification
