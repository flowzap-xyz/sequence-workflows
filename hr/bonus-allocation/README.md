# Bonus Allocation

Annual bonus allocation workflow with budget pool distribution, performance-based calculation, manager calibration, executive approval, and payroll processing.

**Domain:** hr  
**Complexity:** 3/5  
**Tags:** [bonus-allocation, annual-bonus, performance-bonus, budget-pool, calibration, payout]

## Lanes
- **HR/Compensation** - Sets budget pool, calculates targets
- **Management** - Allocates to team, calibrates across org

## Process Flow
1. Finance approves annual bonus budget pool
2. HR distributes pool to departments
3. Calculate target bonus by role/level
4. Manager allocates based on performance
5. Calibration session across teams
6. Executive approval of final allocations
7. Generate bonus letters
8. Process through payroll
9. Communicate to employees
