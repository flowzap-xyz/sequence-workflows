# Job Posting

Job posting workflow with requisition approval, job description drafting, multi-channel posting (LinkedIn, Indeed, career sites), AI resume screening, and ATS candidate tracking.

**Domain:** hr  
**Complexity:** 4/5  
**Tags:** [job-posting, job-requisition, ats, linkedin, indeed, ai-screening, talent-acquisition]

## Lanes
- **Hiring Manager** - Submits requisition, defines requirements, reviews candidates
- **Recruiter** - Reviews requisition, drafts job description, posts to job boards
- **Applicant Tracking System** - Collects applications, AI screens resumes, notifies recruiter

## Process Flow
1. Hiring manager submits job requisition
2. Recruiter reviews and checks headcount approval
3. Draft job description with requirements
4. Select job boards for posting
5. Post to career sites, LinkedIn, and Indeed
6. ATS collects incoming applications
7. AI screens resumes against minimum qualifications
8. Qualified candidates added to candidate pool
9. Unqualified candidates receive auto-rejection
10. Notify recruiter when candidates are ready for review
