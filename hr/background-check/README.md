# Background Check

Pre-employment background check workflow with criminal history search, employment verification, education verification, and drug screening coordination.

**Domain:** hr  
**Complexity:** 3/5  
**Tags:** [background-check, pre-employment, criminal-history, employment-verification, education-verification, drug-screening]

## Lanes
- **HR/Recruiter** - Initiates check, reviews results, makes decision
- **Background Check Vendor** - Conducts searches, returns results

## Process Flow
1. Initiate background check after conditional offer
2. Candidate provides consent and information
3. Submit to background check vendor
4. Run criminal history search
5. Verify employment history
6. Verify education credentials
7. Coordinate drug screening if required
8. Review results for adverse findings
9. Make hire/no-hire decision based on results
