# Load Testing

Load testing workflow with test scenario design, gradual ramp-up, performance metrics collection, bottleneck identification, and capacity recommendations.

**Domain:** devops  
**Complexity:** 4/5  
**Tags:** [load-testing, performance-testing, stress-testing, k6, jmeter, capacity-planning]

## Lanes
- **QA/Performance Team** - Designs tests, analyzes results
- **Load Generator** - Executes load scenarios
- **Target System** - System under test
- **Monitoring** - Collects performance metrics

## Process Flow
1. Define load test scenarios
2. Configure virtual users and ramp-up
3. Set up monitoring dashboards
4. Execute load test
5. Gradually increase load
6. Monitor response times and errors
7. Identify performance bottlenecks
8. Generate performance report
9. Recommend capacity changes
