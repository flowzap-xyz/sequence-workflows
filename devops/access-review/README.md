# Access Review

Quarterly user access review workflow with manager certification, separation of duties validation, remediation tracking, and compliance reporting for audit purposes.

**Domain:** devops  
**Complexity:** 4/5  
**Tags:** [access-review, user-access-certification, quarterly-review, manager-approval, compliance, sod-violations, audit]

## Lanes
- **Compliance Team** - Initiates review, tracks remediation, generates reports
- **Manager Review** - Certifies user access, identifies revocations
- **IT Security** - Processes revocations, validates SoD, updates systems

## Process Flow
1. Initiate quarterly access review
2. Extract user access data from systems
3. Distribute access lists to managers
4. Manager reviews and certifies each user's access
5. Identify access to revoke or modify
6. Check for separation of duties violations
7. Process approved revocations
8. Track remediation of flagged items
9. Generate compliance report for audit
10. Archive review documentation
