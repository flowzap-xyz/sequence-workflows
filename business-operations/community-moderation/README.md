# Community Moderation

Community content moderation workflow with AI auto-flagging, user reports, human review queue, action enforcement, and appeals handling.

**Domain:** business-operations  
**Complexity:** 3/5  
**Tags:** [community-moderation, content-moderation, user-reports, trust-safety, ai-moderation, appeals]

## Lanes
- **AI/Automation** - Auto-flags violating content
- **Moderator** - Reviews flagged content, takes action

## Process Flow
1. User posts content
2. AI scans for policy violations
3. Auto-remove clear violations
4. Queue borderline content for review
5. User reports also enter queue
6. Moderator reviews flagged content
7. Take action (remove, warn, ban)
8. Notify user of action
9. Handle appeals if submitted
