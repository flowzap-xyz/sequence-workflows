# In-App Message

In-app messaging workflow with trigger conditions, audience targeting, message display, user interaction tracking, and conversion measurement.

**Domain:** business-operations  
**Complexity:** 2/5  
**Tags:** [in-app-message, product-tours, tooltips, announcements, user-engagement, intercom]

## Lanes
- **Messaging Platform** - Evaluates triggers, displays messages
- **User** - Views and interacts with messages

## Process Flow
1. User performs trigger action
2. Evaluate targeting rules
3. Check if user already saw message
4. Display in-app message (modal, tooltip, banner)
5. User views message
6. Track impression
7. User clicks CTA or dismisses
8. Record interaction
9. Measure conversion goal
