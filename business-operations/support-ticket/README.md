# Support Ticket

Customer support ticket workflow with auto-categorization, SLA tracking, agent assignment, escalation rules, and satisfaction survey.

**Domain:** business-operations  
**Complexity:** 3/5  
**Tags:** [support-ticket, helpdesk, zendesk, sla, ticket-routing, customer-service]

## Lanes
- **Customer** - Submits ticket, provides feedback
- **Support System** - Routes tickets, tracks SLA
- **Support Agent** - Resolves issues, escalates if needed

## Process Flow
1. Customer submits support request
2. Auto-categorize ticket (billing, technical, etc.)
3. Assign priority based on customer tier
4. Route to appropriate agent/team
5. Start SLA timer
6. Agent investigates and responds
7. Escalate if SLA at risk
8. Resolve and close ticket
9. Send satisfaction survey
