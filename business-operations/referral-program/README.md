# Referral Program

Customer referral program workflow with unique link generation, referral tracking, conversion validation, and dual-sided reward fulfillment.

**Domain:** business-operations  
**Complexity:** 3/5  
**Tags:** [referral-program, viral-growth, referral-tracking, reward-fulfillment, affiliate, word-of-mouth]

## Lanes
- **Referrer** - Shares referral link
- **Referred Friend** - Signs up via link
- **Referral System** - Tracks and validates
- **Rewards** - Fulfills incentives

## Process Flow
1. Customer requests referral link
2. Generate unique tracking link
3. Customer shares link
4. Friend clicks and signs up
5. Track referral attribution
6. Validate conversion (paid signup)
7. Credit referrer's account
8. Send reward to referred friend
9. Notify both parties of reward
