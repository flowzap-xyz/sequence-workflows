# User Onboarding

New user onboarding workflow with welcome email, profile setup, product tour, first action prompt, and activation milestone tracking.

**Domain:** business-operations  
**Complexity:** 2/5  
**Tags:** [user-onboarding, activation, product-tour, welcome-email, first-time-user, time-to-value]

## Lanes
- **New User** - Completes onboarding steps
- **Onboarding System** - Guides user through activation

## Process Flow
1. User completes signup
2. Send welcome email with getting started guide
3. Prompt profile completion
4. Launch interactive product tour
5. Highlight key features
6. Prompt first meaningful action
7. Track activation milestone
8. Trigger follow-up if inactive
9. Mark user as onboarded
