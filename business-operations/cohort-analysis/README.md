# Cohort Analysis

Cohort analysis workflow with user segmentation by signup date, retention curve calculation, LTV projection, and behavioral pattern identification.

**Domain:** business-operations  
**Complexity:** 4/5  
**Tags:** [cohort-analysis, retention-analysis, user-behavior, ltv, churn-prediction, analytics]

## Lanes
- **Data Pipeline** - Collects and processes user data
- **Analytics Engine** - Calculates cohort metrics
- **Visualization** - Renders retention charts
- **Product Team** - Interprets and acts on insights

## Process Flow
1. Define cohort criteria (signup week/month)
2. Segment users into cohorts
3. Track activity over time periods
4. Calculate retention rates per cohort
5. Generate retention matrix
6. Identify high/low performing cohorts
7. Correlate with product changes
8. Project lifetime value
9. Report insights to stakeholders
