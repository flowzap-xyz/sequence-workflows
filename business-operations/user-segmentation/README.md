# User Segmentation

User segmentation workflow with attribute collection, behavioral event tracking, segment rule definition, dynamic membership, and downstream sync.

**Domain:** business-operations  
**Complexity:** 2/5  
**Tags:** [user-segmentation, audience-targeting, behavioral-cohorts, customer-segments, segment, marketing-automation]

## Lanes
- **Data Pipeline** - Collects user attributes and events
- **Segmentation Engine** - Evaluates rules and assigns users

## Process Flow
1. Collect user profile attributes
2. Track behavioral events (page views, purchases)
3. Define segment rules (e.g., "active users last 7 days")
4. Evaluate users against segment criteria
5. Assign users to matching segments
6. Update segment membership dynamically
7. Sync segments to marketing tools
8. Trigger segment-based campaigns
9. Report on segment sizes and trends
