# Plan Upgrade

Subscription plan upgrade workflow with feature comparison, proration calculation, immediate feature unlock, and billing adjustment.

**Domain:** business-operations  
**Complexity:** 3/5  
**Tags:** [plan-upgrade, upsell, proration, feature-unlock, expansion-revenue, billing]

## Lanes
- **Customer** - Initiates upgrade
- **Billing System** - Calculates proration, processes payment
- **Product** - Unlocks new features

## Process Flow
1. Customer views upgrade options
2. Compare current vs new plan features
3. Calculate prorated amount due
4. Display upgrade cost summary
5. Customer confirms upgrade
6. Process prorated payment
7. Update subscription in billing system
8. Unlock new plan features immediately
9. Send upgrade confirmation email
