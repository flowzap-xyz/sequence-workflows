# Webinar Registration

Webinar registration workflow with signup form, calendar invite, reminder email sequence, attendance tracking, and post-event follow-up.

**Domain:** business-operations  
**Complexity:** 3/5  
**Tags:** [webinar, event-registration, zoom, calendar-invite, reminder-sequence, lead-capture]

## Lanes
- **Registrant** - Signs up and attends webinar
- **Marketing System** - Manages registration and reminders
- **Webinar Platform** - Hosts the live event

## Process Flow
1. User submits registration form
2. Capture lead information
3. Send confirmation email with details
4. Add calendar invite (.ics)
5. Send reminder 24 hours before
6. Send reminder 1 hour before
7. Track attendance during webinar
8. Send recording to no-shows
9. Trigger post-event follow-up sequence
