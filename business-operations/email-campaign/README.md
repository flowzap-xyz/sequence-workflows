# Email Campaign

Email marketing campaign workflow with audience segmentation, A/B testing, send scheduling, deliverability monitoring, and engagement analytics.

**Domain:** business-operations  
**Complexity:** 4/5  
**Tags:** [email-campaign, marketing-automation, mailchimp, segmentation, a-b-testing, deliverability]

## Lanes
- **Marketing Team** - Creates content, defines audience
- **Email Platform** - Sends emails, tracks delivery
- **Analytics** - Measures engagement
- **Recipient** - Opens, clicks, converts

## Process Flow
1. Define campaign goal and audience
2. Segment subscriber list
3. Create email content and design
4. Set up A/B test variants
5. Schedule send time
6. Send to test segment first
7. Monitor deliverability and bounces
8. Track opens, clicks, conversions
9. Generate campaign performance report
