# Search Optimization

Search optimization workflow with query analysis, relevance tuning, synonym management, click-through tracking, and A/B testing of ranking algorithms.

**Domain:** business-operations  
**Complexity:** 4/5  
**Tags:** [search-optimization, elasticsearch, relevance-tuning, query-analysis, algolia, search-analytics]

## Lanes
- **Search Analytics** - Tracks queries and clicks
- **Search Team** - Analyzes and tunes
- **Search Engine** - Indexes and ranks
- **Users** - Perform searches

## Process Flow
1. Collect search query logs
2. Analyze zero-result queries
3. Identify low click-through queries
4. Add synonyms and redirects
5. Tune relevance scoring weights
6. A/B test ranking changes
7. Monitor search conversion rate
8. Update index with new content
9. Report on search KPIs
