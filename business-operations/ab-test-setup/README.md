# A/B Test Setup

A/B test setup workflow with hypothesis definition, variant creation, traffic allocation, statistical analysis, and winner deployment.

**Domain:** business-operations  
**Complexity:** 3/5  
**Tags:** [ab-testing, experimentation, split-testing, statistical-significance, conversion-optimization, optimizely]

## Lanes
- **Product Team** - Defines hypothesis and variants
- **Experimentation Platform** - Runs test, analyzes results
- **Users** - Experience control or variant

## Process Flow
1. Define hypothesis and success metric
2. Create control and variant(s)
3. Set traffic allocation percentage
4. Calculate required sample size
5. Launch experiment
6. Collect conversion data
7. Monitor for statistical significance
8. Reach significance or stop early
9. Deploy winning variant
