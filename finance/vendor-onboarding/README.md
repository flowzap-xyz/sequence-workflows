# Vendor Onboarding

Vendor onboarding workflow with application review, W-9/W-8BEN verification, insurance certificate validation, background checks, and compliance approval before vendor activation.

**Domain:** finance  
**Complexity:** 4/5  
**Tags:** [vendor-onboarding, supplier-management, w9-verification, insurance-compliance, background-check, payment-terms, procurement]

## Lanes
- **Vendor** - Submits registration, uploads documents, receives approval
- **Procurement** - Reviews application, assigns category, sets payment terms
- **Compliance** - Verifies tax forms, checks insurance, runs background check

## Process Flow
1. Vendor submits registration form
2. Procurement reviews application and validates business need
3. Request additional information if needed
4. Assign vendor category and set payment terms
5. Vendor uploads required documents (W-9, insurance)
6. Compliance verifies W-9 or W-8BEN tax forms
7. Check insurance certificates for coverage
8. Run background check on vendor
9. Approve or reject based on compliance results
10. Notify vendor of approval status
