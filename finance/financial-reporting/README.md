# Financial Reporting

Financial reporting workflow with GAAP-compliant statement preparation, management review, audit committee approval, and SEC filing for public companies.

**Domain:** finance  
**Complexity:** 4/5  
**Tags:** [financial-reporting, gaap-compliance, income-statement, balance-sheet, cash-flow-statement, sec-filing]

## Lanes
- **Accounting Team** - Prepares statements, makes adjustments
- **Controller** - Reviews for GAAP compliance, approves
- **Executive/Board** - Final review, SEC filing authorization

## Process Flow
1. Close accounting period
2. Generate trial balance
3. Prepare income statement
4. Prepare balance sheet
5. Prepare cash flow statement
6. Review for GAAP compliance
7. Make adjusting entries as needed
8. Controller approval
9. Audit committee review
10. File with SEC (10-K/10-Q for public companies)
