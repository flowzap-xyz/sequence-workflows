# Yearly Audit

Annual financial audit workflow with external auditor engagement, document preparation, fieldwork coordination, findings remediation, and management letter response.

**Domain:** finance  
**Complexity:** 4/5  
**Tags:** [annual-audit, external-auditors, sox-compliance, financial-statements, audit-findings, management-letter]

## Lanes
- **Finance Team** - Prepares documents, coordinates with auditors
- **External Auditors** - Conducts fieldwork, issues findings
- **Management** - Reviews findings, provides responses

## Process Flow
1. Engage external audit firm
2. Prepare PBC (Prepared by Client) documents
3. Auditors conduct planning and risk assessment
4. Fieldwork: test controls and substantive procedures
5. Review preliminary findings with management
6. Remediate identified issues
7. Receive draft audit report
8. Prepare management letter response
9. Issue final audited financial statements
