# Internal Controls

Internal controls testing workflow with risk assessment, control design evaluation, operating effectiveness testing, deficiency identification, and remediation tracking.

**Domain:** finance  
**Complexity:** 4/5  
**Tags:** [internal-controls, sox-compliance, control-testing, segregation-of-duties, risk-assessment, remediation]

## Lanes
- **Internal Audit** - Performs risk assessment, tests controls
- **Control Owners** - Provides evidence, remediates deficiencies
- **Management** - Reviews findings, approves remediation plans

## Process Flow
1. Perform annual risk assessment
2. Identify key controls for testing
3. Evaluate control design effectiveness
4. Test operating effectiveness with samples
5. Document test results and exceptions
6. Classify deficiencies (significant/material)
7. Develop remediation plans with owners
8. Track remediation to completion
9. Report control status to audit committee
